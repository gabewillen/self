# self-common

Shared **MDScripts**, templates, and hooks for the self pack. **Not an agent skill.**

Other skills link workflows here (e.g. `../self-common/workflows/goal-mdscript.md`).  
`/self-learn` runs `workflows/self-learn.mdscript.md` via the `self` router / Stop hooks.

Do not add a `SKILL.md` here — install treats this as a shared pack, not a discoverable skill.
