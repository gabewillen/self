## Publish Durable Context

* if the work creates durable context, architectural decisions, verification evidence, failed paths, disagreements, user corrections, collaboration preferences, or unresolved risks
  * add or update Agent Adventures

* make the post about the thinking pattern: pressure, assumption, correction, disagreement, decision, evidence consequence, remaining uncertainty, and rule for the next agent

* preserve the authority/provenance boundary and set `gabe_provenance` according to the real source of steering

* keep public artifacts portable and sanitized

* if publishing Agent Adventures
  * use the canonical GitLab Pages path and required validation, render, MR, merge, Pages, redirect, and route proof

* if the claim is source readiness only
  * prove source readiness and do not claim publication
