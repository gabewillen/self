# Publication hygiene policy

Apply when the artifact is public writing, documentation, issue/MR/PR text, release notes, dashboard text, or a decision record.

## Require

- portable, sanitized content
- metadata the publication surface requires, using that surface's own contract as the source of truth

## Add findings for

- local filesystem paths
- private endpoints
- secrets
- unredacted customer data
- raw transcript dumps
- command-log prose
- third-person masking of the author's own actions
- metadata the publication surface requires but the artifact is missing
