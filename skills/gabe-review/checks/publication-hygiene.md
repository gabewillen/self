## Check Publication Hygiene

* if the artifact is public writing, blog content, issue/MR/PR text, release notes, dashboard text, or a decision record
  * require portable, sanitized content

* add findings for local filesystem paths, private endpoints, secrets, unredacted customer data, raw transcript dumps, command-log posts, missing `published_at`, missing `project`, missing or unsupported `gabe_provenance`, or third-person masking of the article author's own actions

* for Agent Adventures writing
  * require the pressure, assumption, correction, decision, evidence consequence, remaining uncertainty, and rule for the next agent
